# Security Policy

iHateImages runs entirely in the browser and has no backend, so there is no server to attack and no user data stored anywhere. Even so, if you find a security problem, we want to hear about it.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately instead:

- Use GitHub private vulnerability reporting on this repository (the Security tab, then "Report a vulnerability"), or
- Message the maintainer on X at https://x.com/AlokTom19637918.

Include the steps to reproduce the issue and, if you can, a suggested fix. You can expect a reply within a few days.

## What is worth reporting

- Any way to make the app send a user's image off their device.
- Cross site scripting or code injection in the app.
- A dependency with a known vulnerability that affects the app.

## Supported versions

The version deployed at https://ihateimages.com is the one that is maintained.
